## Set up

Draw a 3-by-3 grid on each sheet. Put the same nine easy targets in both grids, but arrange them differently. Use familiar symbols, colours, shapes, or the numbers 1–9. Place the sheets side by side and put one lid on each grid.

## How to play

One player calls a target. The other scans both grids, slides the left-hand lid onto that target in the left grid, and slides the right-hand lid onto the matching target in the right grid. Try to make both lids arrive together.

Pause briefly on the pair, return both lids to the bottom edges, and call the next target. Swap caller and finder regularly. The caller can name a target, point to a matching card, or draw it in the air.

If one hand arrives first, leave it in place while the other finishes. Begin with four or six targets if nine makes the search frustrating.
