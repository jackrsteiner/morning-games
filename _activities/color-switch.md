## Set up

Put one colour on the back of each hand and a different colour on each palm, so the child wears four colours in total. Sit together at a table with both of the child's hands resting flat.

## How to play

Hold up a coloured object or name a colour. The child turns their hands so only that colour faces up, then holds still to show you.

Mix single calls with pairs: “Green and blue!” means both hands must flip into place at once. Sometimes repeat a colour, sometimes switch quickly between palm and back colours on the same hand.

Let the child check their own hands before you confirm. If a colour is hiding, pause, look at both hands, and turn the right one over slowly.

## Make it easier

Use two colours only, one on the back of each hand. Show the object instead of naming the colour.

## Make it harder

Call colours by name only, give two-step calls (“Red, then yellow”), or ask for one hand palm-up and the other palm-down. Then swap roles so the child calls colours for you.
