# Agent instructions

- Treat each file in `_activities/` as a self-contained game.
- Use `_templates/activity.md` as the schema for new games.
- Keep the core activity playable in seven minutes; prefer one coherent game over a circuit of unrelated exercises.
- Do not repeat the seven-minute duration in activity front matter, cards, or instructions; it is implicit across the collection.
- Put optional printable or media resources in `assets/resources/` and link them in the activity front matter.
- Do not manually add games to `index.html`; the collection is discovered and alphabetized automatically.
- Use short, descriptive, lowercase filenames with hyphens.
- Preserve plain language, accessibility, mobile layout, and reduced-motion support.
- Before committing structural or styling changes, preview the index and at least one activity page.
